# 微信

路径按常见的微信 8.0 版本写，**以实际界面为准**。读取通讯录和会话列表慢时，参考 `iphone-use` 的微信长列表说明（只读 Cell 文字可用 `snapshot_max_depth=13`）。

## 找到 ta

- 首页顶部搜索或「通讯录」里搜备注名 / 昵称 / 微信号 → 打开资料页。
- 核对：头像、备注、昵称、地区、共同群。和档案对不上或有多个候选时停下来问。
- 资料页截图观察一次，作为参考头像（见 ta 档案）。

## 痕迹清单

| 痕迹 | 参考位置 | 动作 | 级别 | ta 那边 |
| --- | --- | --- | --- | --- |
| 单聊会话 | 「微信」会话列表 | 左滑 →「删除」（不是「不显示」）→ 确认 | L2 | 不受影响 |
| 单聊记录（保留会话入口时） | 聊天页 → 右上角「···」→「清空聊天记录」 | 确认清空 | L2 | 不受影响 |
| 聊天里的图片、文件缓存 | 「我 → 设置 → 通用 → 存储空间」里的聊天记录管理 | 选中和 ta 的会话 → 删除 | L2 | 不受影响 |
| 群聊里 ta 的消息 | 群聊 →「···」→「查找聊天记录」→ 按群成员选 ta | 逐条长按 →「多选」→ 删除 | L2 | 不受影响；默认不做 |
| 收藏 | 「我 → 收藏」→ 搜索 ta 的名字，或按聊天记录类收藏逐个看 | 删除对应收藏 | L2 | 不受影响 |
| 置顶、星标、标签、备注 | 会话左滑 / 资料页「设置备注和标签」/「朋友权限」 | 取消置顶、取消星标、从标签移除 | L1 | 不知道 |
| 朋友圈权限 | 资料页「朋友权限」 | 「不让 ta 看」「不看 ta」或「仅聊天」 | L3 | ta 看不到你的朋友圈 |
| 拉黑 | 资料页右上角「···」→「加入黑名单」 | 打开开关并确认 | L3 | ta 发消息会被拒收 |
| 删除好友 | 资料页右上角「···」→「删除」 | 确认弹窗会说明同时删除聊天记录 | L3 | ta 再发消息会提示需要验证 |
| 自己发的含 ta 的朋友圈 | 「我 → 朋友圈」逐条看，或按时间段 | 「设为私密」或删除，由用户选 | L3 | 共同好友看不到了 |
| 亲属卡 | 「我 → 服务 → 钱包」里的亲属卡 | 解除 | L3 | 涉及额度，只在用户明确要求时做 |
| 个人资料里的 ta | 自己的签名、朋友圈封面、拍一拍后缀、状态、情侣头像 | 只指出来，用户想改再改 | — | 共同好友可见 |

## 注意

- 删除好友的确认弹窗通常写着会同时删除聊天记录。用户只同意删好友、想留聊天记录时，先停下来说明这一点。
- 「不显示」只是把会话从列表里隐藏，记录还在；用户要删聊天记录时用「删除」或「清空聊天记录」。
- 共同群聊默认不动；退群属于用户没授权的动作。
- 朋友圈按时间段浏览很慢，先问用户大概时间，或只处理用户记得的那几条。
- 电脑版、平板上的微信，以及「聊天记录迁移与备份」里的备份不受影响，汇报时说明。
