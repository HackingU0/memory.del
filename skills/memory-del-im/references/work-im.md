# 企业微信、钉钉、飞书

工作 IM 默认**不处理**：只有用户在问询时明确点名，才进入这个 App。

## 为什么默认不动

- 账号通常属于公司或组织，聊天记录可能被组织留存或审计，本机删除不影响组织侧的记录。
- 删除同事、退出工作群可能影响工作，而且对方容易察觉。
- 部分消息有已读状态，打开会话会让 ta 那边显示已读。只读盘点时尽量从会话列表看，不点进未读的会话；必须点进去前先告诉用户。

## 用户明确要求时可以做的

| 痕迹 | 参考位置 | 级别 |
| --- | --- | --- |
| 单聊会话 | 会话列表左滑或长按 → 删除 / 移除会话 | L2（本机） |
| 置顶、星标、特别关注 | 会话或资料页 | L1 |
| 个人收藏里和 ta 有关的 | 收藏 / 我的收藏 | L2 |
| 外部联系人（非同事） | 资料页 → 删除联系人 | L3 |

## 不做

- 删除组织内同事、退出组织或工作群、撤回消息、修改组织通讯录。
- 删除钉钉 DING、审批、日程这类工作流记录。

做完后提醒用户：组织侧的聊天留存不受影响。
