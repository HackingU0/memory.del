# 支付宝、购物、外卖、地图、出行

这些 App 里和 ta 有关的通常不是聊天，而是**地址、常用联系人、绑定关系和共享位置**。主要在绝情模式下处理，或用户点名时处理。入口位置以实际界面为准。

| App | 痕迹 | 一般位置 | 级别 | 说明 |
| --- | --- | --- | --- | --- |
| 支付宝 | 好友、聊天 | 「朋友」/ 通讯录 | L2（聊天）/ L3（删好友） | 转账记录不处理 |
| 支付宝 | 亲情卡、亲密付 | 「我的」里的相关服务 | L3 | 涉及额度，只在用户明确要求时做，并提醒 |
| 支付宝 | 合种、共同的小程序活动 | 蚂蚁森林等 | L3 | 退出可能通知对方，先说明 |
| 淘宝 / 京东 / 拼多多 | 收货地址里 ta 的地址 | 「我的 → 设置 → 收货地址」 | L2 | 不影响历史订单 |
| 淘宝 | 亲情号、代付关系 | 「我的」里的相关服务 | L3 | 先说明 |
| 美团 / 饿了么 | 收货地址 | 「我的 → 收货地址」 | L2 | |
| 高德 / 百度地图 | 收藏的地点（ta 家、常去的店） | 「我的 → 收藏」 | L2 | 地名是否算痕迹先问 |
| 高德 / 百度地图 | 家人地图、位置共享、组队出行 | 对应入口 | L3 | 停止共享后对方会看到 |
| 铁路12306 | 常用乘车人里的 ta | 「我的 → 乘车人」 | L2 | 删除后需要再买票时重新添加 |
| 携程 / 飞猪 | 常用旅客、常用联系人 | 「我的 → 常用信息」 | L2 | |
| 滴滴出行 | 紧急联系人、亲友代叫 / 亲友出行 | 「安全中心」或设置 | L2 / L3 | 紧急联系人改成谁由用户决定 |

## 注意

- 常用乘车人、常用旅客里有 ta 的身份证件信息，删除是合理的清理，但仍按 L2 列清单确认。
- 历史订单、账单、转账记录不处理，多数也无法删除。
- 需要支付密码、短信验证码时交给用户，不代输。
