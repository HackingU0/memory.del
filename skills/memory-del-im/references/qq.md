# QQ

QQ 改版频繁，以下是常见入口，**以实际界面为准**。

## 找到 ta

- 「消息」顶部搜索或「联系人」里搜备注 / 昵称 / QQ 号 → 打开资料卡，核对头像、QQ 号、备注、共同群。

## 痕迹清单

| 痕迹 | 参考位置 | 动作 | 级别 | ta 那边 |
| --- | --- | --- | --- | --- |
| 会话入口 | 「消息」列表 | 左滑删除会话 | L1 | 不受影响 |
| 单聊记录 | 聊天页右上角菜单 → 聊天设置 → 删除 / 清空聊天记录 | 确认 | L2 | 不受影响 |
| 聊天里的图片和文件 | 聊天设置里的聊天文件、或「设置」里的存储空间管理 | 删除 | L2 | 不受影响 |
| 群聊里 ta 的消息 | 群聊 → 查找聊天记录 → 按成员 | 逐条删除 | L2 | 默认不做 |
| 收藏 | 「我的收藏」搜索 | 删除 | L2 | 不受影响 |
| 特别关心、分组、备注 | 资料卡 | 取消特别关心、移出分组 | L1 | 不知道 |
| 亲密关系、互动标识 | 资料卡上的关系标识、亲密关系设置 | 解除 | L3 | ta 可能收到提示，先说明 |
| 情侣空间等绑定 | 对应入口（新版可能已下线） | 解除 | L3 | ta 可能收到提示 |
| QQ 空间动态 | 自己的空间 | 设为私密或删除，由用户选 | L3 | 共同好友看不到了 |
| 拉黑 / 屏蔽 | 资料卡右上角菜单 | 加入黑名单 | L3 | ta 发消息会被拒收 |
| 删除好友 | 资料卡右上角菜单 → 删除好友 | 确认 | L3 | ta 的好友列表里可能还在或显示单向 |

## 注意

- QQ 里「删除会话」和「删除聊天记录」常常是两个动作，只删会话入口，聊天记录还在。按用户范围分别处理。
- 亲密关系、情侣空间这类绑定关系解除时，对方可能会收到系统提示。一定先说明，单独确认。
- QQ 登录过期很常见，需要重新登录时交给用户，不要代输密码或验证码。
