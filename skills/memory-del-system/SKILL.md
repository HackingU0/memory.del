# 系统 App：通讯录、通话、备忘录、共享位置等

前提：已经按 `memory-del` 完成范围问询和 ta 档案，并取得本对话的 READY。规则以 `memory-del` 的安全规则为准。系统 App 的界面随 iOS 版本变化，下表路径是参考，以实际观察为准。

bundle ID 是常见的系统 App 标识；`pua_launch_app` 启动失败时，用 `pua_apps(source="installed", query=...)` 核对后再启动，不要连续猜测。

| 痕迹 | App（bundle ID） | 参考位置与动作 | 级别 | ta 那边 |
| --- | --- | --- | --- | --- |
| 联系人 | 通讯录（`com.apple.MobileAddressBook`） | 搜索 → 打开联系人 → 编辑 → 最下方「删除联系人」 | L2 | 不知道 |
| 通话记录 | 电话（`com.apple.mobilephone`） | 「最近通话」→ 编辑，或左滑单条删除；只删和 ta 的那几条，不用「清除」全部 | L2 | 不知道 |
| 短信 / iMessage | 信息（`com.apple.MobileSMS`） | 会话左滑 → 删除；iOS 可能先放进「最近删除」，需要时再永久删除（L4） | L2 | 不受影响 |
| 信息里的「与你共享」 | 信息 → 与 ta 的会话 → 详情 | 关闭「在『与你共享』中显示」 | L1 | 不知道 |
| FaceTime 记录 | FaceTime（`com.apple.facetime`） | 左滑删除和 ta 的通话 | L2 | 不知道 |
| 备忘录 | 备忘录（`com.apple.mobilenotes`） | 搜索 ta 的名字 → 逐条看 → 删除（进「最近删除」）；和 ta 共享的备忘录先问 | L2 / L3 | 共享的：ta 可能看到你离开 |
| 纪念日、生日、约会 | 日历（`com.apple.mobilecal`） | 搜索事件 → 删除；重复事件会问「仅删除此事件 / 所有将来事件」，按用户意思选 | L2 | 共享日历上的事件 ta 能看到变化 |
| 共享日历 / 共享提醒列表 | 日历、提醒事项（`com.apple.reminders`） | 退出 ta 共享的日历或列表；自己共享给 ta 的，停止共享 | L3 | ta 会看到变化 |
| 共享位置 | 查找（`com.apple.findmy`） | 「联系人」里选 ta →「停止共享我的位置」；ta 共享给你的可以移除 | L3 | ta 会发现看不到你的位置了 |
| 紧急联系人 | 健康（`com.apple.Health`） | 医疗急救卡 → 编辑 → 删除紧急联系人 | L2 | 不知道 |
| 家人共享 | 设置（`com.apple.Preferences`）→ 账户 → 家人共享 | 只指出来；移除成员影响购买项目和订阅，由用户自己决定并操作 | L3 | ta 会收到变化 |
| 共享文件夹 | 文件（`com.apple.DocumentsApp`） | 找到共享文件夹 → 停止共享或移除自己 | L3 | ta 可能看到变化 |
| 语音备忘录 | 语音备忘录（`com.apple.VoiceMemos`） | 按标题或日期找到 → 删除（进「最近删除」） | L2 | 不知道 |
| 键盘文本替换 | 设置 → 通用 → 键盘 → 文本替换 | 删除和 ta 有关的短语（例如 ta 的地址、昵称） | L2 | 不知道 |

## 注意

- 通讯录开了 iCloud 同步时，删除联系人会同步到所有设备。删除前提醒一次。
- 删除联系人后，微信等 App 里 ta 的备注不受影响；通话记录里会只显示号码。如果用户也要清通话记录，先删通话记录再删联系人更容易辨认。
- 「查找」里停止共享位置是用户最容易后悔、也最容易被 ta 发现的动作之一，一定单独确认。用户如果出于安全原因想停止共享，直接帮忙，不追问原因。
- 家人共享涉及 Apple 账号、购买和订阅，只解释，不代为操作。
- 系统设置、Apple 账号、密码、Face ID 相关的页面需要认证时，交给用户。
