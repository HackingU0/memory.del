# ta 档案

整个清理过程都靠这份档案判断「这是不是 ta」。档案只保存在本对话里，不写文件、不写进任何 App。

## 字段

| 字段 | 来源 | 用途 |
| --- | --- | --- |
| 称呼、爱称、英文名 | 用户告知 | 截图 OCR 搜索、聊天截图标题 |
| 各 App 的备注名 / 昵称 / 账号（微信号、QQ 号、微博昵称等） | 用户告知，或在 App 里只读确认 | 找联系人、识别聊天截图 |
| 手机号 | 用户告知或通讯录 | 通讯录、电话、信息、OCR |
| 参考头像 | 在 ta 的资料页取一次截图观察（`pua_observe(mode="screenshot")`） | 截图里的头像比对 |
| 「照片」人物名，以及用户自己是否标成了「我」 | 只读查看「人物」 | 人物筛选、合影 |
| 时间段、地点 | 用户告知 | 缩小照片范围 |
| ta 的宠物、标志性物品 | 用户愿意说时 | 描述搜索的补充，不单独作为判断依据 |
| 例外 | 用户告知 | 执行时跳过 |

## 确认身份

- 在每个 App 里先搜索备注名或昵称，**只读**打开资料页，核对头像、地区、共同群、备注等，与档案一致才算找到。
- 搜索结果有多个候选（同名、昵称相近、曾用名），或者资料和档案对不上时，停下来把候选列给用户选，不要自己挑第一个。
- 找不到时不要换着花样猜，问用户 ta 在这个 App 里的名字。用户也不确定就跳过这个 App，在清单里记为「未找到」。
- 「照片」里的人物没有命名时，可以打开几个面孔较多的未命名人物给用户在手机上看，由用户指认；不要凭描述自行认定。
- 人脸聚类可能把长得像的人（兄弟姐妹、双胞胎）放到同一个人物里，执行前抽几张让用户确认。

## 参考头像

参考头像只在本次观察中使用：在 ta 的资料页取截图观察，记住头像的颜色、构图、主体等可描述的特征，用于后面判断截图里的头像。ta 换过头像时，旧截图里可能是旧头像，所以头像不一致不能直接说明不是 ta，要结合聊天标题、文字和时间判断，拿不准就标「存疑」。
