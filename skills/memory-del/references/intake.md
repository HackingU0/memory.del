# 范围问询

开始任何手机操作之前完成问询。目标是拿到五样东西：**删什么**、**ta 是谁**、**怎么删**、**哪些留着**、**涉及哪些 App**。用户已经说过的不再问；能用一次提问问完的不拆成多次。

## 第一问：删什么

必须先问这一问，其余问题都依赖它的答案。纯文字版本（没有提问工具时直接用）：

```text
先说好范围，我再动手。想清掉哪些？可以多选，回数字就行：

1. 截图：和 ta 的聊天截图、ta 的朋友圈或主页截图、转账截图等
2. ta 的样子：只有 ta 一个人的照片、自拍、视频
3. 合影：你们的合照（有 ta 在里面的多人照片算不算，下一步再问你）
4. 聊天记录：微信、QQ 等里和 ta 的对话
5. 好友：删好友、拉黑、取关，或者只是屏蔽
6. 绝情模式：以上全部，再加上通讯录、备忘录、日历、收藏、收货地址、共享位置等能找到的所有痕迹

删除前我都会先列清单给你过目，不会直接删。
```

宿主的提问工具每题选项有上限时（例如 Claude Code 每题 2–4 个选项、最多 4 题），拆成：

- 「清理力度」：我来挑 / 绝情模式（全部痕迹）
- 「相册」（多选）：截图 / ta 的样子 / 合影
- 「社交软件」（多选）：聊天记录 / 好友关系

选了绝情模式时，后两题视为全选，不需要用户再勾。

## 后续追问（只问和所选范围有关的）

| 条件 | 要问的 | 为什么 |
| --- | --- | --- |
| 总是 | ta 怎么称呼？在微信 / QQ 等里的备注名或昵称是什么？有没有爱称、常用的英文名？ | 截图文字搜索和找联系人都靠这些 |
| 选了相册 | 「照片」的「人物」里有没有给 ta 起名字？你自己有没有标成「我」？ | 能否直接按人物筛选；合影需要你自己的人物 |
| 选了相册 | 大概的时间段？有没有特别的地点（ta 家、学校、一起旅行的城市）？ | 缩小范围，给侦察加约束 |
| 选了合影 | 多人合照里有 ta（比如和朋友聚会的大合照）算不算？ | 用户最常意见不一的地方 |
| 选了相册 | 删除方式：A 删到「最近删除」，30 天内可以反悔（推荐）；B 先 AirDrop 备份到 Mac 再删；C 先移到「隐藏」相簿，不删；D 彻底删除，连「最近删除」也清掉 | 决定执行方式和是否需要认证 |
| 选了好友 | 每个 App 想怎么处理：删除好友 / 拉黑 / 只屏蔽朋友圈或动态 / 取消关注 / 不动 | 这些动作 ta 可能察觉，需要明确 |
| 选了聊天记录 | 只删和 ta 的单聊，还是群聊里 ta 发的消息也要删？（群聊逐条删很慢） | 默认只删单聊 |
| 总是 | 你们主要在哪些 App 上有交集？说不清也没关系，READY 之后我查一下手机上装了哪些再问你 | 决定 IM 侦察范围 |
| 总是 | 有没有一定要留下的？比如共同好友的群、工作群、某几张照片 | 例外清单，执行时跳过 |

绝情模式额外问一句：**ta 可能察觉的动作**（删好友、拉黑、取关、停止共享位置、退出共享相簿、解除情侣空间或亲属卡等）要一起做，还是只做 ta 察觉不到的部分？

## 复述计划并等开始

问完后用一小段话复述：范围、ta 的识别信息、删除方式、例外、涉及的 App、会单独确认的高风险动作。然后等用户明确说「开始」「可以」之类的话。用户修改后再复述一次。

```text
我理解的计划：
- 范围：截图 + 合影（多人大合照不算）
- ta：微信备注「小鱼」，照片人物里叫「于某」，时间 2023-05 到 2025-08
- 方式：删到「最近删除」，30 天内可恢复
- 不动：「大学室友」群、2024 年毕业照
- 先找后删：每类先列清单给你看，确认后才删

可以的话我就连接手机开始找。
```

## 不要做的事

- 不要在问询阶段顺手打开手机「先看看」。
- 不要替用户决定删除方式或好友处理方式；没问到的高风险动作一律不做。
- 不要追问感情细节，只问清理需要的信息。
