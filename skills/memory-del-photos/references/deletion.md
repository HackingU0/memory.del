# 删除步骤

只在用户确认过对应类别和数量后执行。每一步都以实际观察到的界面为准；按钮名称、位置随 iOS 版本变化。

## 1. 删到「最近删除」（默认）

1. 回到侦察时记录的视图（某个人物、某次搜索结果、「截屏」分类等），确认看到的是同一批照片。
2. 点「选择」，逐张点选清单里的照片。只选清单里的，跳过例外和用户说保留的。
   - 逐张点比拖动选择稳：拖动在 PUA 里可能被当成滚动。需要大批量连续选择时，先在一小段上试一次，看实际选中了哪些。
   - 网格滚动后位置会变，滚动后重新观察再点。
3. 读出界面上的已选数量（如「已选择 24 张照片」），与本批计划对齐。不一致时停下，先找出差异。
4. 点删除（垃圾桶），出现确认面板后**先观察文案**：
   - 普通情况是「删除 N 张照片」，并说明会从 iCloud 照片和所有设备删除之类的提示。
   - 文案里出现「共享图库」「所有参与者」「共享相簿」等字样，停下来问用户，不点。
5. 确认删除后重新观察：视图里少了这批照片；需要时到「最近删除」看数量（打开「最近删除」需要认证，不是必须的，一般用视图数量核对即可）。
6. 每批建议不超过 50 张，便于核对和中断。

## 2. 先备份到 Mac 再删（用户选了备份时）

1. 选中本批照片 → 共享 → AirDrop → 用户的 Mac，按 `iphone-use` 的 AirDrop 说明操作。
2. 等用户确认 Mac 上收到了（或在能访问本机的宿主里检查 `~/Downloads`），并核对数量。
3. 确认收到后再按第 1 节删除。备份位置告诉用户，不要自行移动或重命名用户的文件。

## 3. 移到「隐藏」（用户选了不删，只是不想看到）

选中后在「更多」菜单里选「隐藏」，确认文案后执行。隐藏的照片在「隐藏」相簿里，默认需要 Face ID 才能打开。提醒用户：隐藏不是删除，iCloud 里仍有。

## 4. 彻底删除（L4，单独确认）

1. 再确认一次：「这 N 张从最近删除里永久删除后无法恢复，确定吗？」
2. 打开「最近删除」需要 Face ID 或密码，按 `iphone-use` 的认证接管流程请用户完成。
3. 进入后点「选择」，**只选本次删掉的那些**。本次删除的项目一般显示剩余天数最多（30 天左右），并且按删除时间排在一起；对着清单逐张核对缩略图，不确定的不选。
4. 读出已选数量，与本次删除的总数核对。
5. 点「删除」，观察确认文案（「这些项目将被永久删除」之类），确认后再观察数量。
6. 绝不点「全部删除」，除非用户明确说过最近删除里的所有东西都可以删。

## 5. 视频、实况照片、连拍

- 实况照片删除时会连同动态部分一起删除，不需要额外处理。
- 连拍只显示一张代表照片时，删除代表照片会删除整组连拍；确认面板会提示张数，以面板为准。
- 「重复项」里合并或删除时，先确认副本也都是清单里的照片。

## 出错时

- 选中数量不对、确认面板文案没见过、删除后数量没变：停下，截图观察，告诉用户。
- 工具返回 `uncertain` 或超时：先观察当前视图和数量，确认是否已经删除，不重放删除。
- 中途需要认证或手机锁屏：按 `iphone-use` 的认证接管处理，恢复后重新观察，从当前状态继续，不沿用旧坐标。
