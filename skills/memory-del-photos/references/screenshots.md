# 截图识别

截图的特点是没有拍摄地点、人物识别通常无效，主要靠**文字**和**界面结构**判断，其次是**头像**。

## 先缩小到截图

- 「媒体类型 → 截屏」（部分版本叫「屏幕快照」），以及「屏幕录制」。
- 也可以在搜索框输入「截屏」，再叠加 ta 的名字、账号做组合搜索；组合结果不对时分开搜索，再人工交叉。
- 按问询给出的时间段浏览，可以大大减少需要逐张看的数量。

## 按界面结构判断

| 截图类型 | 看哪里 | 判断 |
| --- | --- | --- |
| 微信 / QQ 单聊 | 顶部标题栏的名字 | 是 ta 的备注名或昵称 → 确定 |
| 微信 / QQ 群聊 | 标题是群名；气泡旁的昵称 | ta 只是群成员之一时标「存疑」，问用户 |
| 朋友圈、QQ 空间、微博、小红书、抖音的动态 | 发布者昵称和头像 | 发布者是 ta → 确定；ta 只在评论或点赞里出现 → 存疑 |
| 个人主页 / 资料卡 | 昵称、账号、头像 | 与档案一致 → 确定 |
| 转账、红包、收款记录 | 对方名字 | 与档案一致 → 确定 |
| 通话记录、短信、通讯录 | 名字、号码 | 与档案一致 → 确定 |
| 地图、外卖、购物订单 | 收货人、地址、共享位置的人 | 与档案一致 → 很可能，问用户这类算不算 |
| 只有聊天内容、标题被裁掉 | 气泡里的称呼、头像 | 至少两条证据一致 → 很可能；否则存疑 |

## 头像比对

1. 在建档时取得 ta 的参考头像（资料页截图观察）。用户说 ta 换过头像时，问一下以前用的头像大概是什么样。
2. 截图里头像通常很小，必要时在「照片」里双指放大到头像区域，再观察。
3. 比较可描述的特征：颜色、构图、主体（人像、动物、动漫角色、风景）、是否有文字。
4. 头像一致只是中等信号，要再配合标题、文字、时间之一，才能标「很可能」。只有头像一致时标「存疑」。
5. 系统默认头像、热门头像（同一张网图很多人用）不能作为证据。

## 文字识别搜索的技巧

- 备注名、昵称、微信号、QQ 号、手机号（中间带空格或不带的写法都试试）。
- ta 的签名、口头禅、常用的英文名只在用户提供时搜。
- 常见爱称（宝宝、亲爱的）、常见字（姓氏单字）命中范围太宽，只用来补漏，结果逐张看。
- 搜索框会把输入识别成「人物 / 地点 / 文字」等不同类型的建议，选「文字」类或包含该文字的照片那一项；选错类型时结果会完全不同。

## 交给用户确认

「存疑」的截图逐张在「照片」里全屏打开，请用户看手机屏幕（或预览）回答删还是留。一次给用户看的不要超过 5 张，以免用户看漏。
